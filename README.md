## 项目概述

这是一套完整的德州扑克游戏系统，包含 Unity 客户端与 C++ 高性能服务端。系统涵盖俱乐部、代理、MTT/SNG 锦标赛、多人实时对战及后台管理等功能。

> **技术亮点**：生产环境稳定运行 2 年以上 | 支持 10 余种玩法模式 | Unity 客户端适配 iOS/Android | C++ 服务端高并发支持


## 核心功能

| 分类 | 功能列表 |
| :--- | :--- |
| **游戏模式** | 德州扑克、奥马哈、短牌、大菠萝、MTT、SNG、牛仔德州 |
| **社交体系** | 俱乐部系统、联盟代理、好友房（私人局）、语音/视频聊天 |
| **玩法特色** | 保险系统、战绩统计、机器人陪练、实时语音、礼物系统 |
| **赛事系统** | 多桌锦标赛（MTT）、坐满即玩（SNG） |
| **管理后台** | 管理员面板、充值系统、商城系统、排行榜 |

## 技术栈

| 组件 | 技术选型 |
| :--- | :--- |
| **客户端** | Unity（C#）—— 支持 iOS / Android |
| **服务端** | C++ —— 高性能、高并发 |
| **数据库** | MySQL + Redis |


## 系统架构

- **客户端 ↔ 服务端**：基于自定义协议实时通信
- **服务端 ↔ 数据库**：MySQL 持久化存储，Redis 缓存与会话管理
- **部署方式**：支持云服务器或物理机部署


## 🚀 技术栈

- **客户端**：Unity (C#) - 支持iOS/Android

- **数据库**：MySQL + Redis
