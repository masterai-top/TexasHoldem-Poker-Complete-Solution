
# 德州扑克客户端界面规范

## 游戏模式
1. GameType : [Game, Cash, Club] 目前就三种

## UI 预制制作
1. Mudule 目录, 下面存放UI一系列文件夹
   1) Animatioms 动画
   2) Audio 音效
   3) Effect 特效
   4) Materials 材质
   5) Prefabs 预制
   6) Texture 纹理
2. 默认不针对游戏模式进行区分制作的情况下，就在具体文件夹下按需存放
3. 如果要对游戏模式进行区分制作的情况下，就在具体文件夹下新建目录，名字用GameType命名，然后按需存放，并且文件名如果和外面重名的，添加后缀 [_game, _cash, _club]
   eg: 原来的邮件预制 p_email，分目录后
    ```
    Modules                                     Modules 
       |__ Email                                   |__ Email 
           |__ Prefabs                                 |__ Prefabs
               |__ p_email.prefab    =>                    |__ p_email.prefab
           |__ ...                                         |__ Game
                                                               |__ p_email_game.prefab
                                                           |__ Cash
                                                               |__ p_email_cash.prefab
                                                           |__ Club
                                                               |__ p_email_club.prefab
                                                       |__ ...
    ```                            

        

## UI 界面开发
1. 首先是注册界面配置
    配置文件在 utils/page_config.lua 下
2. 注册函数
```Lua
-- 注册函数定义
local function R(path, folder, games, ...) end
```
3. 基本游戏模式组合, 用来传入 R函数的 games 参数
   1) 默认定义参数
      _game, _cash, _club,
      _game_cash, _game_club, _cash_club,
      _all
   2) 设置不存在的模式使用默认模式，即当前层次结构
   3) 要使用某个模式替代另一个模式，
      在第四个参数中设置，参数结构,以邮件为例，
      此时game模式界面的脚本被cash模式界面给替代了，走cash模式界面逻辑了
      ```Lua
      R("email.view.email_v", "email_v", _all, {game=n_cash})
      ```
   4) lua 脚本目录结构,以邮件界面为例        
    ```
    logics                                  logics
        |__ email                               |__ email
            |__ controller                          |__ controller (controller 下的扩展参照 view 目录)
                |__ email_c.lua                         |__ email_c.lua
            |__ view                                |__ view
                |__ email_v.lua     ==>                 |__ email_v.lua
                                                        |__ email_v_game.lua        (R函数 folder 参数为空, games 中包含 game)
                                                        |__ email_v_cash.lua        (R函数 folder 参数为空, games 中包含 cash)
                                                        |__ email_v_club.lua        (R函数 folder 参数为空, games 中包含 club)
                                   [嵌入小游戏制作规范.md](%C7%B6%C8%EB%D0%A1%D3%CE%CF%B7%D6%C6%D7%F7%B9%E6%B7%B6.md)                     |__ email_v                 (R函数 folder 参数为 email_v 创建的)
                                                            |__ email_v_game.lua    (R函数 folder 参数为 email_v 下的游戏模块, games 中包含 game)
                                                            |__ email_v_cash.lua    (R函数 folder 参数为 email_v 下的游戏模块, games 中包含 cash)
                                                            |__ email_v_club.lua    (R函数 folder 参数为 email_v 下的游戏模块, games 中包含 club)

    ```
4. 注册界面，以邮件界面为例
```Lua
R("email.view.email_v", "", _all)
R("email.view.email_v", "email_v", _all)
R("email.view.email_v", "email_v", _all, {game=n_cash, cash=n_club, club=n_game})
```
