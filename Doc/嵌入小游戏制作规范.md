
# 德州扑克客户端嵌入小游戏规范

## 小游戏框架
1. 通过游戏主体，进行小游戏选择
2. 选择游戏后，进行小游戏加载
3. 下载完成后，进入小游戏
4. 离开小游戏，卸载对应的资源

## UI 预制制作
1. Module/GamePlay 目录, 下面原有的一些内容
2. Module/GamePlayMiniGame 目录, 下面存放新开发的小游戏
   1. MiniGame_XXXX 目录，对用的游戏内容
      1. Game 目录，下面存放游戏玩法上的内容,包括Prefab、UI资源等
      2. Panels 目录，下面存放游戏中对应的界面内容 ,包括Prefab、UI资源等
   ```
       Modules                                    
          |__ GamePlayMiniGame                    
              |__ MiniGame_Cash     
                  |__ Game                              
                      |__ Prefab                   
                      |__ Texture   
                  |__ Panels                              
                      |__ Panel                            
                          |__ Prefab                   
                          |__ Texture                 
                                                  
   ```   
   
## lua 代码
1. logics/gameplay 目录，下面原有的一些内容
2. logics/gameplay_minigame 目录，下面放新开发的小游戏代码
