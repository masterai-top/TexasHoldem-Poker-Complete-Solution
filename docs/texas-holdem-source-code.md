# Texas Hold'em Poker Source Code Overview

This repository presents a multiplayer Texas Hold'em poker solution built around a Unity and C# mobile client, C++ game-server modules, MySQL, and Redis.

## Public project scope

- Unity client resources and platform integration directories
- C++ room, game-state, action, timer, messaging, and database modules
- Poker clubs, alliances, private rooms, MTT, and SNG product workflows
- Product screenshots and technical documentation

## Evaluation checklist

Before using the source code, verify the exact Unity version, compiler and operating-system requirements, third-party dependencies, database schema, protocol specification, admin scope, build scripts, and licensed assets.

The public repository and documentation do not by themselves guarantee production readiness, security, capacity, store approval, or legal compliance.
